2단계

SAR Worst 선정

sar_worst/sar_worst.html

1단계에서 추출된 systemcheckdate.xlsx와 모든 챔버의 시스템 엑셀을 첨부해주세요. Dipole의 Serial 번호별 worst 측정 건을 선정해 Plot No.를 지정합니다.

  • 1g % 최대값 기준, 동률이면 10g %로 판정
  • 기준 엑셀(systemcheckdate.xlsx)과 날짜·대역·Lab이 일치하는 건만 정리
  • 검토 기간(시작일 ~ 종료일) 필터 선택 가능
입력시스템 체크 엑셀 + (선택) 기준 엑셀 출력SystemCheck_Worst.xlsx
SAR Worst 열기 →

권장 작업 순서

  1. Test Date에서 시험 데이터 엑셀을 넣고 systemcheckdate.xlsx를 저장합니다.
  2. SAR Worst에 시스템 체크 엑셀과 함께 위 파일을 넣어 기준 엑셀로 사용합니다.
  3. 결과 엑셀을 다운로드해 보고서에 반영합니다.
각 도구는 Chrome 또는 Edge에서 열어 사용하세요. 엑셀 라이브러리를 인터넷에서 불러오므로 인터넷 연결이 필요합니다.
