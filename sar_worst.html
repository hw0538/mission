시스템 체크 엑셀을 넣으면 정해진 양식으로 모아서 정리하고, Serial 번호가 같은 측정 건끼리 비교해 worst 의 Plot No. 칸에 번호를 붙입니다. 파일은 브라우저 안에서만 처리돼요.

엑셀 파일을 여기로 끌어다 놓기 또는 클릭해서 선택 (.xlsx / .xlsm, 여러 개 가능)

    불러온 모든 파일의 데이터를 합쳐서 Serial 번호가 같은 것끼리 하나의 worst를 고릅니다 (대소문자·공백 무시).
    Worst 기준: |1g Delta| 최대 → 1g 동률이면 |10g Delta| 최대 → 둘 다 동률이면 먼저 측정된 데이터 (소수 둘째 자리 기준, 부호 무시).
    결과 양식: Date Tested · Type · Serial # · T.S. Liquid · Zoom Scan · Normalize · Target · Delta · Plot No. (측정 건마다 1g·10g 줄, 원본에 8g·APD 가 있으면 그 줄도 같은 양식으로 추가, 날짜는 yyyy-mm-dd)
