# SAR System Check · Serial별 Worst 선정

SAR 시스템 체크 엑셀을 넣으면 **모든 파일의 데이터 중 Serial 번호가 같은 측정 건끼리 worst를 골라 Plot No.를 붙이고**, 엑셀은 합치지 않고 **파일마다 시트 하나씩** 보고서 양식 그대로 정리한 결과 엑셀을 만들어 줍니다.

- 설치 없이 HTML 파일을 브라우저로 열어서 씁니다.
- 엑셀 파일은 브라우저 안에서만 처리하고, 서버로 보내지 않습니다.

## 빠른 시작

1. `sar_worst.html`을 더블클릭해서 Chrome이나 Edge로 엽니다.
2. 시스템 체크 엑셀(`.xlsx`, `.xlsm`)을 화면에 끌어다 놓습니다. 여러 개를 한 번에 넣어도 되고, 나눠서 넣어도 됩니다.
3. (선택) **검토 기간**에서 시작일 ~ 종료일(`YYYY-MM-DD`)을 고릅니다. 비워 두면 전체 기간을 검토합니다.
4. 화면에서 결과를 확인합니다. 결과 미리보기의 **파일 탭**을 누르면 파일별 시트를 볼 수 있습니다.
5. **결과 엑셀 다운로드**를 누릅니다. 버튼은 위쪽 패널과 결과 화면의 요약 옆 두 곳에 있습니다.
6. 브라우저 다운로드 폴더에 `SystemCheck_Worst.xlsx`(기간을 정했으면 `SystemCheck_Worst_2024-02-27~2024-05-01.xlsx`처럼 기간이 붙음)가 저장되고, 요약 옆에 저장한 파일 이름과 시트 목록이 표시됩니다.

> 페이지를 처음 열 때 엑셀 라이브러리(ExcelJS)를 인터넷에서 불러오므로, 인터넷 연결이 필요합니다.
>
> 판정 규칙 요약은 화면 맨 아래 **판정 규칙 보기**를 누르면 펼쳐집니다(기본은 접혀 있음).

## 파일 구성

| 파일 | 설명 |
|---|---|
| `sar_worst.html` | 메인 도구. 브라우저에서 열어서 사용 |
| `sar_worst.py` | 같은 로직의 Python 버전 (명령줄에서 일괄 처리할 때) |
| `PRD.md` | 요구사항 문서. 판정 규칙, 양식 인식 규칙, 예외 처리, 검증 결과 |
| `input/` | Python 버전의 기본 입력 폴더 |
| `output/` | Python 버전의 기본 출력 폴더 |

## 검토 기간

| 칸 | 쓰는 법 |
|---|---|
| 검토 기간 | 시작일 ~ 종료일을 달력에서 고릅니다(`YYYY-MM-DD`, 두 날짜 포함). 한쪽만 골라도 됩니다. |
| 전체 기간 | 두 칸을 비워 전체 기간으로 되돌립니다. |

- 기간 밖의 측정 건은 **worst 비교와 결과 시트에서 모두 빠집니다**. 기간을 정하면 날짜를 읽지 못한 측정 건도 빠집니다.
- 기간 안에 측정 건이 없는 파일은 시트를 만들지 않고, 요약 아래에 그 파일 이름을 알려 줍니다.
- 기간 칸 옆에 불러온 데이터의 처음~마지막 날짜가 보여서, 범위를 고를 때 참고할 수 있습니다.
- 기간 설정은 페이지를 새로 고치면 지워집니다.

## Worst 선정 기준

엑셀 표는 합치지 않고, **모든 파일의 데이터 값을 비교**해서 **Serial 번호가 같은 측정 건끼리** worst를 고릅니다. 다른 파일에 있는 같은 Serial도 함께 비교합니다.

1. **|1g Delta|**가 가장 큰 측정 건이 worst입니다.
2. 1g가 같으면 **|10g Delta|**가 더 큰 측정 건이 worst입니다.
3. 둘 다 같으면 **먼저 측정한** 측정 건을 고르고, 결과 엑셀에 동률 메모를 답니다.

- Delta는 소수 둘째 자리 기준으로, 부호 없이 비교합니다.
- Serial은 대소문자와 공백을 무시합니다(`4d174` = `4D174`).
- 8g, APD 행은 결과 표에는 나오지만 판정에는 쓰지 않습니다.
- Serial이 비어 있는 측정 건은 Serial별 비교에는 들어가지 않습니다(아래 보완 규칙에서는 후보가 될 수 있음).
- **번호 없는 시트 보완**: 정리한 뒤 worst 번호가 하나도 없는 파일(시트)이 있으면, 그 파일 전체(Serial 무관)에서 같은 기준으로 worst 하나를 골라 번호를 붙입니다. Worst Summary의 선정 근거에 `번호 없는 파일 → 파일 전체 worst`로 표시됩니다.

## 읽을 수 있는 원본 양식

| 양식 | 한 측정 건의 행 |
|---|---|
| 2줄 양식 | 1g, 10g |
| 4줄 양식 (측정자 열 포함) | 1g, 8g, 10g, APD(4cm^2) |

두 양식이 섞여 있어도 결과는 모두 같은 양식으로 정리됩니다. 열은 헤더 글자(`Date`, `Type`, `Serial`, `Zoom`, `Normalize`, `Target`, `Delta`, `Liquid`/`ELI`)로 찾고, Delta 열은 값이 `(Normalize − Target) / Target × 100`과 맞는지 계산해서 확인합니다. 자세한 규칙은 [PRD.md](PRD.md)의 5.2절을 보세요.

## 결과 엑셀

시트 구성: **넣은 엑셀 파일마다 시트 하나**(시트 이름 = 첨부한 엑셀 파일 이름, 확장자만 뺌) + 마지막에 **Worst Summary**.

예) `A_Feb.xlsx`, `B_Mar.xlsx`를 넣으면 → `A_Feb` | `B_Mar` | `Worst Summary`

**파일 시트** — 그 파일의 측정 건만, 보고서 양식 그대로

| Date Tested | Type | Serial # | T.S. Liquid | | Zoom Scan to 100 mW | Normalize to 1 W | Target (Ref. Value) | Delta ±10 % | Plot No. |
|---|---|---|---|---|---|---|---|---|---|
| 2024-02-27 | D750V2 | 1205 | Head | 1g | 0.92 | 9.2 | 8.55 | 7.02 | **1** |
| | | | | 10g | 0.61 | 6.1 | 5.59 | 9.30 | |

- 날짜는 `yyyy-mm-dd`로 씁니다.
- 원본에 8g, APD 행이 있으면 같은 양식으로 추가하고, 병합 칸도 그만큼 늘어납니다.
- 각 시트 안에서 측정 건은 날짜순으로 정렬됩니다.
- 같은 측정 건이 여러 파일에 있으면 각 파일 시트에 모두 나오고, worst면 그 시트들에 같은 번호가 붙습니다(비교할 때는 한 번만 셉니다).
- 엑셀은 시트 이름을 31자까지만 허용하고 `[ ] : * ? / \`를 쓸 수 없습니다. 파일 이름이 여기에 걸리면 31자로 자르고 금지 문자는 `_`로 바꾸며, 겹치면 ` (2)`를 붙입니다. 이렇게 이름이 바뀐 시트는 **표 위 첫 줄에 `원본 파일: 전체 파일 이름`**이 적힙니다.

**Worst Summary 시트** — Serial마다 worst 하나씩, 선정 근거와 원본 위치(`파일/시트 (행)`)를 함께 보여 줍니다. 아래쪽(I~L열)에는 **시트 이름 ↔ 원본 파일 이름 대응표**가 있습니다.

## 번호 순서

번호 순서는 **하나로 고정**되어 있습니다(고르는 칸 없음).

- **파일 번호 순서**: 파일 이름에 번호가 있으면 **그 번호 순서대로** 파일(시트)을 정렬하고, 첫 시트부터 각 시트 안에서 위에서부터 1, 2, 3…
  - 이름에서 처음 나오는 숫자로 비교합니다: `3_A`, `1_B`, `2_C` → `1_B`, `2_C`, `3_A` / `Check_2`가 `Check_10`보다 앞
  - 처음 숫자가 같으면 다음 숫자까지 비교합니다: `SC_2024-02-26` → `SC_2024-03-05`
  - 번호가 없는 파일은 뒤에 옵니다.
  - 결과 엑셀의 시트 순서, 화면의 파일 목록·탭 순서도 같은 순서입니다.
  - 원하는 순서가 있으면 파일 이름 맨 앞에 `1_`, `2_`처럼 번호를 붙이세요.

## Python 버전

같은 판정 규칙과 같은 결과 엑셀을 명령줄에서 만듭니다. Python 3과 `openpyxl`이 필요합니다.

```bash
pip install openpyxl

python sar_worst.py                          # input 폴더의 엑셀 전부 → output/SystemCheck_Worst.xlsx (파일별 시트)
python sar_worst.py a.xlsx b.xlsx            # 파일 지정
python sar_worst.py input -o result.xlsx     # 폴더와 출력 경로 지정
python sar_worst.py --from 2024-02-27 --to 2024-05-01   # 검토 기간 (두 날짜 포함, 한쪽만 써도 됨)
```

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 다운로드 버튼이 회색(눌리지 않음) | 아직 엑셀을 넣지 않았거나, 넣은 파일에서 시스템 체크 데이터를 찾지 못했습니다. 경고 메시지를 확인합니다. |
| 다운로드했는데 파일이 안 보임 | 브라우저의 다운로드 목록(Ctrl+J)에서 저장 위치를 확인합니다. |
| "ExcelJS 라이브러리를 불러오지 못했어요" | 인터넷 연결을 확인하고 페이지를 새로 고칩니다. |
| ".xlsx/.xlsm 파일만 읽을 수 있어요" | `.xls` 파일은 엑셀에서 `.xlsx`로 다시 저장합니다. |
| "날짜, Type, Delta 열을 찾지 못해 건너뜀" | 헤더 글자가 위 규칙과 다른지 확인합니다. 새 표기는 PRD에 규칙으로 추가해야 합니다. |
| "Serial 이 비어 있어 worst 판정에서 제외" | 원본의 Serial 칸을 채웁니다. |
| "다른 파일과 같은 측정 건 N건은 … 한 번만 셌어요" | 같은 측정 건이 여러 파일에 있다는 뜻입니다. 각 파일 시트에는 그대로 나오고, 비교만 한 번으로 셉니다. 정상 동작입니다. |
| "이미 불러온 파일이라 건너뛰었어요" | 같은 이름의 파일을 다시 넣었습니다. 새로 넣으려면 **초기화** 후 다시 넣습니다. |
| "시작일이 종료일보다 늦어요" | 검토 기간의 두 날짜 순서를 바로잡습니다. |
| "선택한 검토 기간에 해당하는 측정 건이 없어요" | 기간 칸 옆의 "불러온 데이터 기간"을 보고 범위를 다시 고르거나 **전체 기간**을 누릅니다. |
| 결과가 이상함 | Worst Summary 시트의 "원본" 열로 원본 파일과 행을 찾아 값을 비교합니다. |

## 알려진 제약

- 실제 시험 엑셀로는 아직 검증하지 않았습니다. 4줄 양식의 헤더 이름은 추정값입니다.
- 결과 엑셀의 날짜는 글자로 저장되어, 엑셀 날짜 필터나 날짜 계산에 바로 쓸 수 없습니다.
- worst 번호는 굵은 글씨로만 표시하고 색은 칠하지 않습니다.

## 유지보수 규칙

- `sar_worst.html`을 고치면 **`PRD.md`도 같이 고칩니다**(해당 요구사항, 검증 결과, 변경 이력).
- 판정 로직을 바꾸면 `sar_worst.py`도 똑같이 바꾸고, 두 결과 엑셀이 같은지 확인합니다.
