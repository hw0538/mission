# Test Date

여러 SAR 시험 데이터 엑셀에서 System Check Date를 모아 **날짜 · 시스템 대역 · SAR Lab.** 요약 표로 정리합니다.

## 빠른 시작

1. `test_date.html`을 더블클릭해서 Chrome이나 Edge로 엽니다.
2. 엑셀(`.xlsx`, `.xlsm`)을 화면에 끌어다 놓습니다. 여러 개를 한꺼번에 넣어도 됩니다.
3. **실행**을 누릅니다.
4. 화면에서 표를 확인하고 **엑셀로 저장**을 누르면 `systemcheckdate.xlsx`가 다운로드됩니다. 시트는 SAR Lab.별로 나뉘고, 시트 이름은 `SAR 4`처럼 Lab 번호만 씁니다.

## 판정 규칙

- 모든 시트에서 `System Check Date` 헤더가 있는 표를 찾고, 같은 행의 `Frequency (MHz)`와 `SAR Lab.`을 함께 읽습니다.
- 측정 주파수에서 **가장 가까운** 시스템 대역을 고릅니다. 시스템 대역: 13.5, 750, 835, 1750, 1900, 2300, 2450, 2600, 3500, 3700, 3900, 5250, 5600, 5750, 5800, 6000, 8000 MHz
- **13.5 대역은 다이폴 이름 `CLA-13`으로 판정합니다.** 같은 표에 Dipole 열이 있고 값이 `CLA-13`이면, 또는 주파수 칸에 `CLA-13`이 적혀 있으면 13.5로 봅니다.
- 측정 주파수가 두 대역의 정확히 가운데(예: 5775 MHz)이면 두 시스템이 모두 필요하다고 보고 **5750 줄과 5800 줄을 둘 다** 적습니다.
  - 단, 두 대역 중 하나라도 **3000대역(3500/3700/3900)**이면(3050, 3600, 3800, 4575 MHz) 실제로 쓰지 않는 주파수입니다. 그래서 두 줄을 노란색으로 칠하고 비고에 **확인 필요**를 적습니다. 원본 입력을 확인하세요.
- 날짜, 대역, SAR Lab.이 모두 같은 줄은 한 번만 나옵니다.
- 대역과 주파수는 소수점 둘째 자리까지 표시합니다(예: 13.50, 2450.00).
- 정렬은 **SAR Lab. 번호가 작은 순**(SAR 2 → SAR 4 → SAR 10)이고, 같은 Lab 안에서는 날짜순, 같은 날짜 안에서는 대역순입니다.
- 날짜는 있는데 주파수가 비어 있는 행은 결과에서 빠집니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `test_date.html` | 메인 도구. 브라우저에서 열어서 사용 |
| `PRD.md` | 요구사항 문서 |
| `input/` | 원본 엑셀을 두는 폴더 |
| `output/` | 결과 파일을 두는 폴더 |

## 문제 해결

| 메시지 | 해결 |
|---|---|
| 노란 줄 · 비고 "확인 필요" | 3000대역에서 두 시스템의 정확히 가운데인 주파수가 입력돼 있습니다. 원본의 Frequency 값을 확인합니다. |
| ".xlsx/.xlsm 파일만 읽을 수 있어요" | `.xls` 파일은 엑셀에서 `.xlsx`로 다시 저장합니다. |
| "System Check Date가 적힌 행을 찾지 못했어요" | 헤더 이름이 `System Check Date`인지, 날짜 칸이 비어 있지 않은지 확인합니다. |
## 유지보수 규칙

- `test_date.html`을 고치면 **`PRD.md`도 같이 고칩니다**(해당 요구사항, 검증 결과, 변경 이력).
- 이 폴더는 `../sar_worst/`와 독립입니다. 서로의 파일을 참조하지 않습니다.
